# Projektdokumentation

Dieses Verzeichnis bündelt die zentralen Dokumentationsartefakte des Projekts **running_data** (Data Wrangling, HS25).

## Verfügbare Dokumente

1. **[Interaktives Quarto-Notebook (HTML)](data_wrangling.html)**  
   Vollständig gerenderte HTML-Fassung des kanonischen Quarto-Notebooks (`notebooks/data_wrangling.qmd`). Zeigt den schrittweisen Ablauf der Datenverarbeitung, Tabellen, Kennzahlen, Qualitätsmetriken, Limitationen und das Fazit.

2. **[Projektübersicht & Ausführungsanleitung](../README.md)**  
   Hauptdokumentation im Projektstammverzeichnis mit Installationsanleitung, Architekturüberblick, CLI-Aufrufen, Schemabeschreibung und Hinweisen zur Reproduzierbarkeit.

3. **[Testsuite-Dokumentation](../tests/README.md)**  
   Übersicht über die automatisierte Testsuite, Testkategorien und Isolationsprinzipien mit synthetischen Fixtures.

4. **Präsentation und Reproduktionsvideo (Abschluss-Artefakte)**  
   - Die Präsentationsfolien (Dauer: 9–11 Minuten) werden für das Abschlusskolloquium erstellt.
   - Das Reproduktionsvideo (Dauer: max. 5 Minuten) demonstriert die lückenlose Schritt-für-Schritt-Reproduktion vom Klonen über das Setup bis zur Ausführung.
